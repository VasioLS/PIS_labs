# ElectiveHub — учёт факультативов студентов

Учебный проект на Python 3 и Django по индивидуальному варианту
**«Определение факультативов для студентов»** (лабораторный практикум
«Программирование на Python 3.7 + Django», labs 1–7).

## Предметная область

Преподаватели кафедры ведут факультативные занятия по предметам. В базе
хранятся анкетные данные студентов (ФИО, группа, адрес, телефон), учебные
планы факультативов по семестрам (лекции, практика, лабораторные работы),
записи студентов на факультативы и оценки, полученные на экзаменах.

Ключевые правила варианта:

* **Объём факультатива** — сумма часов лекций, практики и лабораторных
  работ по всем его семестрам; факультатив может длиться несколько семестров.
* **Часы задаются в каждом семестре отдельно** — модель `ElectiveSemester`.
* **Студент записывается на факультатив**, а не на отдельный семестр, поэтому
  многoсеместровый предмет остаётся одним предметом.
* **Итоговая оценка за предмет — последняя полученная оценка**: сортировка
  по дате экзамена, при равных датах — по порядку внесения записи
  (`students.models.final_grade`, `final_grades_map`). Пересдача повышает итог.
* **Минимальный объём** — каждый студент обязан прослушать не менее
  `MIN_ELECTIVE_HOURS` часов (по умолчанию 128 ч, настройка в
  `electives/settings.py`). В зачёт идут только семестры с оценкой 3 и выше;
  незакрытые часы активных записей показываются как «в процессе». Оценки
  по отменённым записям остаются в журнале, но часы не зачитываются.
* **Определение факультативов** — для каждого студента система считает
  зачтённые часы, недостающий объём и предлагает факультативы, которые
  позволят набрать минимум (сначала те, что закрывают его полностью).

## Быстрый старт

```bash
cd electives
python -m venv venv                 # если окружения ещё нет
venv\Scripts\activate               # Windows
pip install -r requirements.txt

python manage.py migrate
python manage.py seed_demo          # демонстрационные данные
python manage.py createsuperuser    # учётная запись для /admin/
python manage.py runserver
```

Сайт доступен по адресу <http://127.0.0.1:8000/>, административная панель —
<http://127.0.0.1:8000/admin/>.

Демонстрационные данные создаются командой `seed_demo`; повторный запуск
безопасен (данные не дублируются). Команда `python manage.py seed_demo --reset`
удаляет все записи на факультативы и оценки и создаёт их заново — это удобно,
если демонстрационную базу нужно вернуть в исходное состояние.

Что создаёт `seed_demo`:

* 3 преподавателя кафедры информатики;
* 3 факультатива: «Python для начинающих» (2 семестра, 128 ч),
  «Web-разработка» (2 семестра, 120 ч), «Основы анализа данных» (1 семестр, 48 ч);
* 3 студента с анкетными данными;
* 6 записей на факультативы (завершённые и текущие);
* 6 оценок, включая пересдачу по Python: 4 балла, затем 5 — итоговой
  становится 5 (последняя по дате экзамена);
* двух студентов, выполнивших минимум 128 ч, и одного, которому не хватает
  20 ч (для него система предлагает подходящий факультатив).

## Как проверяется вариант

| Требование варианта | Где реализовано |
| --- | --- |
| Анкетные данные студента: ФИО, группа, адрес, телефон | `Student`, форма `/students/add/`, карточка студента |
| Преподаватели кафедры ведут занятия | `Teacher`, поле `Elective.teacher`, колонка «Преподаватель» |
| По факультативу задан объём часов и вид занятий | `ElectiveSemester` (лекции, практика, лабораторные) |
| Факультатив может длиться несколько семестров | несколько `ElectiveSemester` у одного `Elective` |
| Студент записывается на факультативы | `/enroll/`, `/unenroll/`, статусы записи |
| Оценки по окончании семестра | `Grade` с датой экзамена, форма `/grades/add/` |
| Итоговая оценка — последняя полученная | `final_grade()`, `final_grades_map()`, страница `/grades/` |
| Минимальный объём факультативов для студента | `students/progress.py`, страница `/requirements/` |
| Определение факультативов для студента | блок «Определение факультативов» в карточке студента |
| Django: модели, админка, шаблоны, статика, авторизация, JavaScript | проект `electives`, приложение `students` |

| Адрес | Назначение |

| `/` | Сводка: студенты, факультативы, семестры, записи, оценки, выполнение минимума |

## Модели

| Модель | Назначение | Связи |
| --- | --- | --- |
| `Teacher` | Преподаватель кафедры | — |
| `Student` | Студент: ФИО, группа, адрес, телефон | 1→N `Enrollment`, `Grade` |
| `Elective` | Факультатив: название, описание, преподаватель, набор открыт/закрыт | 1→N `ElectiveSemester`, `Enrollment` |
| `ElectiveSemester` | Объём занятий факультатива в семестре: лекции, практика, лабораторные | N→1 `Elective`; 1→N `Grade` |
| `Enrollment` | Запись студента на факультатив (одна пара «студент + факультатив», статус: обучается / завершил / отменена) | N→1 `Student`, `Elective` |
| `Grade` | Оценка 2–5 за экзамен по семестру факультатива с датой | N→1 `Student`, `ElectiveSemester` |

Целостность обеспечивают ограничения БД: уникальность пары «студент +
факультатив», уникальность семестра в учебном году, диапазон оценки 2–5.
